# Seguridad y API

Controla quién accede a qué con permisos granulares, perfiles de usuario, equipos y claves de API — con buenas prácticas de aislamiento por organización y LGPD.

## Para qué sirve

- Dueños y administradores que configuran la organización, equipos e integraciones
- Gerentes que organizan rotación de atención y supervisión por equipo
- Agentes con acceso limitado (datos ocultos, filtros restringidos)
- Desarrolladores que integran sistemas vía API y webhooks

## Qué puedes hacer

- Configurar organización: nombre, logo, zona horaria, idioma y preferencias de atención
- Definir perfiles granulares: owner, admin, manager, agent, agent_limited, financial, sales, medical_*
- Ocultar datos de contacto de agentes y restringir visibilidad del CRM por equipo (LGPD)
- Gestionar [equipos](/es/guide/teams/) con líderes, flujo automático al transferir y rotación inteligente
- Configurar rotación con disparadores, modos auto-atender/reservar, fallback, horarios y guardia
- Conectar integraciones: [OpenAI](/es/guide/integrations/openai), [DeepSeek](/es/guide/integrations/deepseek), [ElevenLabs](/es/guide/integrations/elevenlabs), [Minimax](/es/guide/integrations/minimax), [Firecrawl](/es/guide/integrations/firecrawl) y [S3](/es/guide/integrations/s3)
- Generar [claves de API](/es/guide/integrations/api-keys) para integración con la [API Interflow](/es/api/)
- Controlar visibilidad de canales y pausar flujos al tomar atención manualmente

## Cómo se conecta

- **[Chat y atención](/es/features/chat)** — permisos de canal, ocultación de contactos, transferencia por equipo
- **[CRM y clientes](/es/features/crm)** — control de acceso por equipo y datos sensibles
- **[Automatización e IA](/es/features/automation)** — integraciones de IA, TTS y webhooks
- **[Informes](/es/features/reports)** — visibilidad de métricas según perfil
