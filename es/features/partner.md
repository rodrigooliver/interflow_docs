# Portal del socio

Gestiona organizaciones revendidas, planes personalizados, facturas, comisiones y wallet Asaas — todo en un portal dedicado para socios de la plataforma.

## Para qué sirve

- Revendedores y agencias white-label que administran cartera de clientes
- Socios que configuran wallet Asaas para recibir split de ingresos
- Programas de comisionamiento con facturas y repartos automatizados
- Gestores de red que necesitan visión centralizada de las organizaciones hijas

::: info Acceso
Disponible para socios con programa aceptado y estado activo en la plataforma.
:::

## Qué puedes hacer

- Gestionar organizaciones revendidas (crear, configurar, monitorear)
- Crear y editar planes personalizados para cada organización hija
- Monitorear facturas y comisiones generadas por el programa de socios
- Configurar wallet Asaas (`asaas_wallet_id`) para split automático de ingresos
- Visualizar estado y facturación de las organizaciones gestionadas

## Cómo se conecta

- **[Facturación](/es/features/billing)** — la facturación de organizaciones hijas puede ser gestionada por el socio
- **[Configuración](/es/guide/settings/)** — suscripción y configuración de cada organización tenant
- Financiero y Facturación de cada tenant permanecen separados del portal del socio
