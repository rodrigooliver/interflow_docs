# Closure Types

Standardize why a chat was closed and optionally start an `attendance_closure` flow (e.g. CSAT).

::: tip Access
Sidebar → **Closure types**.
:::

1. Create a type (name)
2. Optionally link an `attendance_closure` flow
3. Agents pick it when closing a chat

## Order

The list follows the order set by an administrator. The same sequence appears when closing a chat, in the conversation, and in the close-attendance flow node.

1. On the type list, hold the handle to the left of the name
2. Drag it to the position you want and drop it
3. The order is saved immediately. A new type is added at the end
4. Clear search before reordering: while the filter is active, dragging is paused
