# Shared folder

The shared folder is the team's place for support files. It is separate from chat attachments and from a customer's documents.

## Where to open it

In the side menu, **Shared folder**.

## Folders

The **+** on each column header creates a folder or uploads files into that folder. Folders can sit inside other folders. Drag a file onto a folder to move it.

Column view opens one column for each folder in the path. List view shows only the current folder; switching back to columns shows the path again.

The page address includes the open folder, so the link can be copied and opened directly.

## Files

Click a file to open its details: type, size, and who uploaded it. **Open**, in the file menu or the panel, shows the preview. **Download** saves the file. HTML is saved too, instead of opening as a page.

The list loads 30 items at a time. Scroll to the end or use **Load more**.

Each upload can be up to 50 MB and counts toward the organization's storage quota.

## Who can delete

The person who uploaded a file can delete it. Deleting someone else's file, or an empty folder, depends on the shared-folder delete permission. Deleting also removes the file from storage.

## Permission

The module is called Shared folder, inside the organization's permissions. Without the create permission, a person can see and download, but cannot upload or create folders.
