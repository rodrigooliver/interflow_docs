# Automation & AI

Automate support, lead qualification, and internal processes with visual flows, conversational AI agents, and integrations with external services.

## What it's for

- Businesses that want 24/7 support without growing the team
- Sales teams automating lead qualification and follow-up
- Operations that need CSAT/NPS on closure or actions when CRM stages change
- Developers integrating systems via webhooks and HTTP

## What you can do

- Build flows in the [visual drag-and-drop editor](/en/guide/flows/builder) with dozens of node types
- Use specialized flows: closure (`attendance_closure`), CRM stage change (`crm_stage_change`), team transfer (`team_transfer`), scheduling (`appointment_status_change`), and background processing (`bulk_silent`)
- Configure triggers by channel, schedule, keyword, first contact, or webhook
- Create [AI agents](/en/guide/ai-agents/) with knowledge base (RAG), tools, and fallback between agents
- Equip agents with [tools](/en/guide/ai-agents/tools/) for CRM, schedule, transfer, external API, web search, and funnel
- Automate tasks with the create-task node, documents with the document node, and sales with the POS node
- Integrate OpenAI, DeepSeek, ElevenLabs, Minimax, and Firecrawl for AI, voice, and web scraping
- Measure response rate in funnels with [Checkpoint](/en/guide/flows/follow-up-response-rate)
- Process actions in the background with silent flows, without direct customer contact

## How it connects

- **[Chat & Support](/en/features/chat)** — flows reply to conversations and AI agents handle support in real time
- **[CRM & Customers](/en/features/crm)** — stage changes trigger automations; nodes update customer data
- **[Schedule](/en/features/schedule)** — agents schedule, confirm, and react to status changes
- **[Tasks](/en/features/tasks)** — flows create tasks; project automations start silent flows
