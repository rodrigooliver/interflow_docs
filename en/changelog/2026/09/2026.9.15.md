## New Features

### A decision before the AI Agent

Before the conversation model runs, the agent can use JEV to decide whether it should act. The decision does not write a reply. It only picks one option.

It applies to automatic attendance. Starting a flow by hand skips this decision.

#### What it is for

- Skip a reply when the person is not the customer, for example a relative
- Pause automatic attendance on this chat when it is already clear the agent should stop
- Wait for the next message when the answer is still uncertain
- Go straight to the agent when the customer is already on a known tag or stage

#### How to use it

1. Open the AI Agent and go to **Decision**
2. Turn on **Evaluate before running the agent**
3. Optionally add conditions by tag or stage: block the agent, or skip the decision
4. Write the instruction and add outcome options: continue, pause automatic attendance, or try again
5. On each option, you can also update the customer: add tags, remove tags, or move the stage

When the agent does not continue, the chat gets a system message with the reason. Tag and stage changes still appear in the customer history.

> Full guide: [Decision before the agent](/en/guide/ai-agents/decision-gate)

---

## Benefits

- The conversation model only runs when the decision allows it
- Automatic attendance can stop without blocking a manual start
- The reason for not replying stays visible in the chat
