## New Features

### Exclude tags in bulk messages

When creating or editing a campaign, you can pick tags that **must not** receive the send — for example `stop messages`, `opt out`, or any organization tag. Anyone with one of those tags is left out, even if they also match a stage or an included tag.

#### What is it for?

- Honor unsubscribe requests without removing contacts from include lists
- Avoid sending to people who asked to stop receiving campaigns
- Refine the audience before you confirm the send
- See the recipient estimate with exclusions already applied

#### How to use it?

1. Open **Bulk messages** and create or edit a campaign
2. Under **Recipient filters**, use **Tags** to include the audience
3. Under **Excluded tags**, check the tags that should stay out
4. Review the estimate: it already subtracts anyone with an excluded tag
5. Save and start the campaign when you are ready

A tag cannot be selected on both sides at once. If **Excluded tags** is empty, behavior stays the same as before.

> Full guide: [Bulk messages — exclude tags](/en/guide/chat/bulk-messages#exclude-tags)

- Fewer unwanted sends and better respect for opt-out requests
