## New Features

### Shared folder

The team now has one place to keep support files, without email or an outside tool.

> Full guide: [Shared folder](/en/guide/files/shared-folder)

#### What it is for
- Everyone in the organization can upload and download the same files
- Folders and subfolders keep the material organized
- Images, video, PDF, HTML, and other types the browser can read open on the same screen
- Deleting a file also removes it from storage

#### How to use it
1. Open **Shared folder** in the menu
2. Create folders from the **+** on the column header, or upload from there or by dragging
3. Click a file to see its details. **Open**, in the file menu, shows the preview
4. **Download** saves the file, including HTML
5. Drag a file onto another folder to move it

Column view shows the open path. List view shows only the current folder. The address keeps the folder (`?folder=`), so refresh and the browser back button reopen the same place. The list loads 30 items at a time and fetches more on scroll or with **Load more**.

Each file can be up to 50 MB and counts toward the organization's storage quota. The person who uploaded a file can delete it. Deleting anyone's file requires the shared-folder delete permission.

## Benefits

- Support files stay in Interflow, visible to the team
- Less passing files around by email or an external drive
- Preview without downloading, and a real download when someone wants to save the file
