## New Features

### Outbound webhooks

The organization sends events to its own HTTPS URL, in **Settings → Webhooks**.

#### What it is for
- Notify another system when a customer changes funnel stage, is created, a conversation closes, a chat moves to another team, a task is created, or an appointment status changes
- Sign the POST with HMAC, or send it unsigned
- See each attempt and resend it from the Deliveries tab

#### How to use it
1. Open **Settings → Webhooks**
2. Register the URL, the events, and a secret if you want signing
3. Use **Test** and follow the result in **Deliveries**

> Full guide: [Outbound webhooks](/en/guide/integrations/webhooks)

---

## Benefits

- The integration receives the customer, the action, and UTM data when it exists
- Network failures and HTTP 5xx are retried on a spaced schedule
- Each POST attempt is kept for 90 days
