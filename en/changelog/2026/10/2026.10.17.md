## New Features

### Bases

Bases is an organization table for records that do not belong on the customer profile. Each base has columns, pages (rows), views, and forms.

Open it in **Settings**, in the **Customers** group, right under **Custom fields**.

#### What it is for
- Keep your own lists (internal orders, equipment, classes, checklists)
- Link each page to a customer, a chat, or an appointment
- Show customer-linked bases on the customer profile
- Build a table, calendar, chart, or report from the same pages
- Publish a form with required fields and who can submit it

#### How to use it
1. Open **Settings** and click **Bases**
2. Name the base and create it
3. From the column header, edit the name, type, and description
4. The description shows as a tooltip on the header and as placeholder text in an empty field
5. Choose the link: none, customer, chat, or appointment
6. Create pages, views, and forms from the base menu

Column types: text, number, yes/no, date, select, multi-select, email, phone, link, files, relation, formula, and rollup.

A formula uses the column key in braces, for example `{preco} * {qtd}`.
