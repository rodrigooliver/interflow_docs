## New Features

### CRM stage on customer import

The customer import spreadsheet now accepts the funnel stage along with name, WhatsApp, email, tags, and custom fields.

#### What it is for
- Bring in a list already placed on the right stages, without moving each customer afterward
- Update an existing customer by contact and put them on the stage in the file

#### How to use
1. In **Customers**, open **Import**
2. Choose the funnel. The screen lists the accepted stage names
3. In the `stage` column, write the stage name in that funnel (for example, Proposal sent)
4. An empty cell does not change the stage of someone already on file
5. If the name does not exist in the funnel, the import stops and points to the row so you can fix the file

The value is the stage name, not a code. Matching ignores capitalization and extra spaces at the ends.

> Guide: [Customers — Stage in the spreadsheet](/en/guide/crm/customers#stage-in-the-spreadsheet)

## Benefits

- Profile, tags, custom fields, and stage go in together
- The sales base starts organized on the funnel stages
- A wrong name is reported before anything is saved, so the file can be fixed
