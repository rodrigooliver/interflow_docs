## New Features

### Telegram Bot channel

The organization connects a Telegram bot and handles direct messages and groups in the same inbox as the other channels. The customer talks to the bot, not to a personal phone number.

#### What it's for
- Receive text, images, video, audio, and files sent to the bot
- Reply from the Interflow conversation, with no 24-hour window
- Handle groups the bot has been added to

#### How to use it
1. In Telegram, open **@BotFather**, send `/start`, then `/newbot`
2. The display name may include spaces (`Interflow Bot`). The username cannot include spaces and must end in `bot` (`Interflow_Bot`). `Interflow` and `Interflow Bot` are rejected as usernames
3. When the reply is **Done**, copy only the token line. Do not forward that message. If it leaked, use `/revoke`
4. In **Settings → Channels → New channel**, choose **Telegram Bot**
5. Name the channel, paste the token, and save
6. The API must be on a public HTTPS address so Telegram can deliver messages
7. Optional: `/setdescription` and `/setuserpic` in BotFather for the bot text and photo
8. To read every message in a group, add the bot to the group and send `/setprivacy` to BotFather, then choose **Disable**

#### Limits
- There is no delivered or read receipt. The message stays sent once Telegram accepts it
- Each text message is limited to 4096 characters
- Telegram broadcast channels and personal-number login are not part of this channel
