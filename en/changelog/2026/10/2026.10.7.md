## New Features

### Closure type order

An administrator sets the sequence of closure types. That order shows up when closing a chat, in the conversation, and in the close-attendance flow.

#### What is it for?
- Put the most used reasons first
- Give the team one shared sequence
- Avoid an unordered list at close time

#### How to use it
1. Open **Settings** → **Closure types**
2. Drag the handle of each type to the position you want
3. The order is saved when you drop it. A new type is added at the end
4. While search is filled in, dragging is paused so a filtered subset does not rewrite the full order

> Guide: [Closure types — Order](/en/guide/chat/closure-types#order)

---

## Benefits

- Agents find the right reason faster
- Each team keeps the sequence that matches its process
