## New Features

### Conversations on the dashboard

The conversations card on the dashboard shows the list for the selected quick filter, the same one that person would see in the inbox. Tasks and appointments stay on the same screen.

#### What is it for?
- See conversations, tasks, and appointments without leaving the dashboard
- Switch the list (assigned to me, unassigned, groups, and the organization's other quick filters)
- Open the conversation right there and return to the dashboard when you close it

#### How to use it?
1. Open the **Dashboard**
2. On the conversations card, click the title (the current filter name)
3. Pick a filter from the menu
4. Click a conversation to open it
5. **View all** opens the inbox already on that filter

The list has a limited height and scrolls when it grows. It updates as new conversations match the same filter.

---

## Benefits

- Support stays on the same screen as tasks and appointments
- The filter is the inbox filter, so the person only sees conversations they would already see there
