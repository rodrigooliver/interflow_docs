## New Features

### Default description for a financial category

Each income or expense category can have a default text. When you create an entry and pick the category, the description is filled in and stays editable.

#### What it is for
- Keep repeating entries consistent
- Skip typing the same description every time

#### How to use it
1. In **Financial → Categories**, open the category and fill in **Default transaction description**
2. When creating income or an expense, select the category: the description is filled in
3. If you already changed the text, switching categories does not replace what you typed
4. A category with no default text does not clear a description you already wrote
5. When editing an existing entry, the saved description stays
6. **Generate with AI** also suggests that sentence for each category and subcategory

> Guide: [Financial — Categories](/en/guide/financial/#categories)

---

## Benefits

- Recording money in and out is faster, with consistent descriptions
- The suggested text can be adjusted on the entry without changing the category
