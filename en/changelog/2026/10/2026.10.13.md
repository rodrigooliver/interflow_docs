## New Features

### Chat audio transcription

Conversation audio is now transcribed with **GPT Transcribe**. If that call fails, the system uses ElevenLabs **Scribe v2**.

In the audio message menu, **Transcribe with another model** lets you pick either model. You can run it again even when a transcript already exists. Anyone with the chat open sees the new text right away.

On the Interflow AI credit balance:

- GPT Transcribe: US$ 0.005 per minute
- Scribe v2: US$ 0.004 per minute

Your own provider key does not debit that balance.

### Transcribe a file into a customer note

While editing a note, **Transcribe audio** uploads a file and appends the text at the end of the note. The note is saved only when you click save.

- Model: GPT Transcribe or Scribe v2
- On Scribe, **No Verbatim** removes hesitations and non-speech sounds
- A long file is split into parts of up to 10 minutes
- The audio is not stored: only the text goes into the note

> Guide: [Customers — Notes](/en/guide/crm/customers#transcribe-audio)

---

## Benefits

- Chat transcription still works when one model fails
- You can compare both models on the same message
- A long recording becomes note text without listening to the whole file
- The audio file is not kept in storage
