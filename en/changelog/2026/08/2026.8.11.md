## New Features

### Task templates

Each task project can have **reusable drafts**. Creating a task from a template pre-fills title, description, relative due date, stage, priority, status, assignees, labels, and checklist.

> Full guide: [Tasks — Task templates](/en/guide/tasks/task-templates)

#### What is it for?

- Standardize repeating work (onboarding, follow-up, post-sale)
- Avoid filling the same fields on every new task
- Set due date as days from creation (today, 1, 2, 7, or a custom value)

#### How to use?

1. Open the project in **Tasks** → project menu → **Templates**
2. Click **New template** and fill in the draft
3. On **Add task**, use the arrow to pick a template — or **Blank task** to start from scratch
4. Review the fields and save

---

### Templates in automations and macros

The **Create task** action in [project automations](/en/guide/tasks/project-automations) and [customer macros](/en/guide/crm/customer-macros) can use a project template. The title still accepts variables (current task title, customer name, status, priority). In automations, the template is also a **condition** (task created from a given draft).

#### What is it for?

- Automatic follow-ups that already match the team standard
- A customer-profile macro that opens the right task without building it from scratch
- Rules that only run when the task came from a specific template

---

### Optional columns in the task list

In **List** view, the **Columns** selector shows or hides customer, stage, labels, and checklist. The choice is saved. There is also a **refresh** button to reload the board, list, and projects without reloading the page.

#### How to use?

1. Open the project (or **My Tasks**) in **List** view
2. Click **Columns** and pick what you want to see
3. Use the refresh icon in the project bar when you need to reload data

---

## Benefits

- Recurring tasks stay consistent, with less rework
- Automations and macros reuse the same draft
- The list shows only the columns the team uses day to day
- Refresh the screen without leaving the open project
