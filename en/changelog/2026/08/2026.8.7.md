## New Features

### Expanded editor for long messages

When the message field grows past about **6 lines** and starts to scroll, an **expand** button appears. It opens a larger editor with the same writing tools (bold, italic, emoji, and AI improve). On mobile, the editor takes the **full screen**.

> Guide: [Chat interface — shortcuts and message field](/en/guide/chat/interface#keyboard-shortcuts)

#### What is it for?

- Write long texts without being stuck in a small field
- Use formatting and AI with more space, including on mobile
- Send with the button (or `Ctrl+Enter` / `⌘+Enter` on desktop)

#### How to use?

1. Type the message in the chat field
2. When part of the text is hidden, click the expand icon
3. Keep writing in the editor; **Enter** inserts a new line
4. Send with the button or close to return to the compact field — the text is kept

---

## Bug Fixes

### Enter on mobile sent the message

On mobile, the keyboard Enter key sent the message instead of inserting a new line. **Enter now breaks the line**; sending is done with the send button. On desktop, behavior is unchanged: Enter sends and Shift+Enter inserts a new line.

### Empty space in the AI improve modal

On desktop, the **AI improve** modal left a large gap between the result field and the footer. Height now follows the content. The “Result” label above the field was also removed.
