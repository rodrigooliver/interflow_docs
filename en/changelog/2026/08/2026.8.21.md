## New Features

### Messages and customer data on the AI Agent

Each agent can now control **how much history** and **which customer data** go into the context sent to the model. On the **Context** tab, **Messages and customer data** opens the settings: chat message limit (default 50) and whether the profile is included — yes, no, or only some fields. With **Yes**, you can turn on **Mask data** and pick what to hide (tax ID, email, phone). Channel and system date/time stay in context.

> Guide: [AI Agents — Messages and customer data](/en/guide/ai-agents/#messages-and-customer-data)

#### What is it for?

- Long conversations: send only the last N messages, without blowing the token budget
- Privacy: keep a full tax ID (or any profile data) out of the model
- Agents that do not need the profile: turn customer data off in one step

#### How to use it?

1. Open the AI Agent on the **Context** tab
2. Click **Messages and customer data**
3. Set the **message limit** (1 to 200; default 50)
4. Under **Customer data**, choose **Yes**, **No**, or **Some**
5. If **Yes**, enable **Mask data** and the fields that should be partially hidden
6. If **Some**, mark what to send and, optionally, what to mask
7. Close the modal and **save** the agent context

Existing agents without this setting behave as before: 50 messages and all data, unmasked.

---

## Benefits

- Fewer tokens on long chats, with the history you choose
- Sensitive data (document, contact, address) can be masked or left out of the model
- Per-agent control, without changing other agents
