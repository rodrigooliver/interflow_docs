## New Features

### Origin channel and conditions on the AI Agent

The same AI Agent can serve **several channels** and know where the conversation started. In the first context message, it receives the current channel (name, type, ID, and identifier, such as the WhatsApp number).

You can also tailor the experience with **channel**, **funnel stage**, and **tag** conditions:

- if / else blocks in the prompt text (highlighted in the editor)
- on each **extra context** (matching blocks become a single text at the end)
- on each **ready-made tool** (the action is only available when the condition matches)

Empty = always. Multiple items of the same type = OR. Different types = AND.

On the **Test** tab, use **Simulate context** to pick channel, stage, and tags and validate the slice without a live conversation.

> Full guide: [AI Agents — Channel and conditions](/en/guide/ai-agents/channel-conditions)

#### What is it for?

- One agent for sales WhatsApp, support, and Instagram, with different tone and flow
- Enable transfer, scheduling, or API only on certain channels, stages, or tags
- Reuse WhatsApp lists and extra texts with a filter, without duplicating the agent

#### How to use?

1. Open the AI Agent on the **Context** tab
2. In the editor, use the branch button to insert an if / else block
3. In **Extra Contexts**, set **Show when**
4. On the **Tools** tab, on each ready-made action, use **Available when**
5. On the **Test** tab, open **Simulate context** and chat as the customer
