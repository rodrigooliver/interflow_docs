## New Features

### Quick filters with multiple channels

In **quick filters** and the chat filters panel, you can now select **more than one channel** at once — for example, two or more WhatsApp numbers — and see conversations from those channels together in the same list.

Previously, each filter accepted only one channel (or none, to list all). With multi-select, teams build tailored views without constantly switching filters.

#### What is it for?

- Group conversations from specific numbers into a single custom filter
- Split operations by channel sets (e.g. store A + store B) without mixing the rest
- Give supervisors and teams that run multiple WhatsApp numbers more flexibility

#### How to use?

1. In the conversations menu, open **quick filters configuration** (admin/owner)
2. Edit the criteria for the desired filter (or duplicate an existing one)
3. In the **Channels** section, select one or more available channels
4. Save and apply the filter — conversations from the chosen channels appear together
5. With no channels selected, behavior stays the same as before: all connected channels

The same multi-channel selection is also available in the **side filters panel** and in saved attendance filters.

> Full guide: [Chat interface — Filters](/en/guide/chat/interface#custom-filters)
