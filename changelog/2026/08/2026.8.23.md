## Novas Funcionalidades

### Executar Agente IA em uma mensagem

No menu de uma mensagem do cliente ou do agente, o atendente escolhe **Executar agente IA**, seleciona um agente da organização e dispara só aquele prompt — **sem iniciar fluxo**.

O modelo recebe **apenas a mensagem escolhida**, mais data, canal e dados do cliente. Não lê o histórico do chat. As ferramentas (CRM, tags, funil, base de conhecimento, criar chat) são as mesmas do agente. Se **Enviar mensagens pelo agente** estiver ligado, a resposta vai para o chat; se não, o agente só age no cadastro e no atendimento.

Não cria sessão de fluxo e não altera um fluxo que já esteja rodando no chat.

> Guia completo: [Agentes IA — Executar em uma mensagem](/guide/ai-agents/run-on-message)

#### Para que serve?

- Classificar, extrair dados ou atualizar o cliente a partir de uma mensagem pontual
- Responder com o agente sem disparar o fluxo inteiro
- Reusar o mesmo prompt do fluxo, só no recorte daquela mensagem

#### Como usar?

1. Abra a conversa e o menu da mensagem (cliente ou agente)
2. Clique em **Executar agente IA**
3. Busque e selecione o agente (lista em ordem alfabética)
4. Confirme. Aguarde o processamento

::: tip Quem pode executar
A permissão segue a de iniciar fluxo: admin e owner sempre podem. Se a organização impedir fluxo durante o atendimento, os demais usuários também não disparam o agente nesse caso.
:::

## Benefícios

- Ação pontual sem ocupar o fluxo do chat
- Mesmas ferramentas e regras de envio do agente
- Contexto enxuto: só a mensagem escolhida
